# Split App

A full-stack expense splitting application built using MERN stack.

## Features

- User Authentication
- Create Groups
- Add Expenses
- Split Expenses Among Friends
- Track Balances

## Tech Stack

### Frontend
- React.js

### Backend
- Node.js
- Express.js
- MongoDB

## Installation

### Backend

cd splitapp-backend
npm install
npm start

### Frontend

cd splitapp-frontend
npm install
npm start
